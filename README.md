# Subscription Based Business Analysis

## Project Overview
This project is a subscription-business analytics exercise built around a synthetic dataset, Python data generation, SQL schema design, and analytical reporting.

## Business Context
The project models a subscription-based business scenario with acquisition, churn, retention, and product behavior patterns. It was created for learning and analytical practice rather than production reporting.

## Data
- Source type: synthetic CSV data generated in Python
- Data structure: star-schema dimensions and fact tables
- Included evidence: generated data files, SQL schema, SQL exploration scripts, and Power BI assets

## Solution
The project investigates retention and customer behavior through synthetic transaction and engagement data and supports a prototype reporting layer for business exploration.

## Technologies
- Python
- SQL
- Power BI
- synthetic data generation
- analytical SQL and modeling
