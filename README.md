# Subscription Business Analytics

Synthetic subscription analysis using Python-generated data, SQL modeling, and a Power BI reporting prototype.

## Project Overview
This project models a subscription-based business scenario using synthetic data to explore retention, churn, acquisition, delivery-channel behavior, and plan performance. It combines data generation, SQL analysis, and a Power BI reporting prototype in one learning-focused workflow.

## Business Context
This is a self-initiated educational project. The business scenario is modeled for analytical practice and does not represent a live operational subscription environment.

## Problem
The goal was to create a realistic subscription business dataset and test how acquisition, engagement, and churn patterns could be explored in SQL and reporting layers.

## Solution
The repository includes Python code for synthetic dataset generation, SQL schema and analysis files, and a Power BI file for a prototype reporting layer. The analysis supports a star-schema-oriented structure and exploratory business questions.

## Data
- Source type: synthetic CSV data generated in Python
- Data nature: simulated subscription business dataset
- Key files: brightbowl_dataset_generator.py, brightbowl_schema.sql, Meals_EDA.sql, Data/*.csv, SubscriptionBI.pbix

## Technical Approach
- generate synthetic subscription data in Python
- load into SQL schema and dimension/fact tables
- perform exploratory SQL analysis to assess data quality and trends
- build a Power BI prototype for reporting and analysis

## Key Analytical Areas
- customer acquisition and retention analysis
- churn and engagement patterns
- delivery-channel and plan analysis
- marketing spend efficiency
- subscription performance reporting

## Evidence / Scope
The repository includes the synthetic data generation script, SQL schema, analysis source, and Power BI prototype. It is best understood as a self-initiated analytical exercise rather than a production implementation.
